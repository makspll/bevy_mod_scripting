# Migrating from 0.23 to 0.24

## Scripts

### The `types` global is removed

It was deprecated in 0.23. Use `import_namespace`, or `world.get_type_by_name`:

```diff
- local Transform = types.Transform
+ local Transform = import_namespace("transform").Transform
+ -- or
+ local Transform = world.get_type_by_name("bevy_transform::components::transform::Transform")
```

### Types are no longer globals

Globals named after types, like `Vec3` or `Transform`, are gone: types sharing a short name used to shadow each other unpredictably. Import types from their namespace instead. Bevy types with bindings are grouped in namespaces by category (`math`, `ecs`, `time`, `transform`, `ui`, ...), BMS' types live in `bms`, see [Namespaces](../ScriptingReference/namespaces.md):

```diff
+ local Vec3 = import_namespace("math").Vec3
+ local Transform = import_namespace("transform").Transform
  local t = Transform.from_translation(Vec3.new(1, 2, 3))
```

To keep the globals, set `CoreScriptGlobalsPlugin::register_static_references` to `true`.

### `world.get_type_by_name` takes a full path

Short names no longer resolve, neither for Rust types nor for script components. Pass the full type path, i.e. `world.get_type_by_name("bevy_transform::components::transform::Transform")` or `world.get_type_by_name("script.my_game.Enemy")`, or use `import_namespace`, which looks types up by short name within one namespace.

## Rust

- `CoreGlobals::types`, `ScriptTypeCatalogue::flat_view` and `ScriptTypeCatalogue::duplicate_short_names` are removed.
- `ScriptComponentRegistry::find` and `WorldExtensions::get_type_by_name` only take a full path.
- The Lua language server backend no longer marks globals as deprecated: `TypeInstance` lost its `deprecated` field.
- `CoreScriptGlobalsPlugin::register_static_references` defaults to `false`.
- Types with `script_bindings` from the bevy bindings crates, and all types of the bevy crates they cover, are put in category namespaces (see `set_crate_script_namespaces`). Use `app.override_script_namespace` to move a type elsewhere.

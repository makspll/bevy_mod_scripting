# RFCs

An RFC is a request for comments from contributors, users and various other stakeholders. When an RFC is created it is usually done with the intention of gathering opinions and knowledge around the topic.

For BMS the process looks as follows:

- An RFC is created and modified via PRs to the RFC file under `docs/src/RequestsForComments/XX-RFCTITLE/XX-RFCTITLE.md`.
- The creator of an RFC also starts an issue for discussion of the RFC on github linking to the file.
- Once enough perspectives are gathered an RFC can be closed and the decision implemented.
